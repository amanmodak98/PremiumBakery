Animated luxury bakery site — smooth scroll, product showcase.

🔗 **Live demo:** https://premium-bakery.vercel.app/

## Built with
`React` · `Tailwind` · `Framer Motion` · `Vite`

## Features
- Production-ready MERN / React architecture
- Responsive, accessible UI (mobile-first)
